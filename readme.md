# Project Overview

The application helps architects and developers quickly assess early-stage building concepts by extracting structured requirements from natural language descriptions and validating them against parcel constraints using a rule-based engine, with AI assisting in interpretation and explanation.

## Data

Test data was generated using AI and represents sample building parcels and investment requests for demonstration purposes.

- `/data/parcels.json` – sample building plots with zoning constraints
- `/data/projectRequests.json` – sample investor project descriptions

## Purpose

This is a demo dataset created for testing and prototyping a system that matches investment requirements with available building parcels.
